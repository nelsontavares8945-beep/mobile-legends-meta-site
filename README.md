# Projeto MLBB Meta Lab

Este site foi montado como uma aplicação React com Vite para demonstrar um painel de meta de Mobile Legends.

## O que tem
- Lista de campeões por lane
- Filtros por lane e busca por nome/role
- Win rate, pick rate e ban rate
- Build recomendada
- Runas sugeridas
- Itens
- Counters e contra-counter
- Atualização automática simulada

## Como rodar
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o projeto:
   ```bash
   npm run dev
   ```
3. Acesse:
   ```bash
   http://localhost:3000
   ```

## Importante
Sem API oficial do Mobile Legends, a atualização real do meta exige uma fonte externa confiável. Esta versão usa dados locais e refresh automático simulado para manter o painel funcional e pronto para evoluir.
